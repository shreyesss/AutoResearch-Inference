# C02 — Share compatible FlashMLA planning metadata

Status: **Proposed; untested**. Updated: 2026-10-21 (Asia/Calcutta).

**Claim:** Reuse a plan holder within that pass only when all live compatibility fields match. A tensor-shape match alone is insufficient if lengths, masks or graph buffers differ.

**Why:** Compatible attention groups can each rebuild the same execution plan during one metadata-building pass, repeating host work and planner launches.

**Research finding:** Genuinely new to the fresh shortlist: #58818. Its three vLLM source-file changes applied to disposable installed-source copies. No execution, correctness or end-to-end gain was demonstrated.
