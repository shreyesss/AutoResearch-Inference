Warp-specialized architecture for the SM90 FP8 MQA logits kernel.
Replaces the production post-processing path (SHFL+STG inline) with
an epilogue warpgroup that runs overlapped with the next kv-block.

Architecture: 4 TC WGs (512) + 1 Epi WG (128) + 1 TMA WG (128) = 768 threads.
TC does dual-bank WGMMA (N=64 split, warpgroup_wait<1> overlap) +
partial reduce → STS to epi_buf in SMEM. Epi does LDS → horizontal
sum → STG to global. TMA is unchanged.

Key design decisions:
- TC@104 regs (0 spill): full weights[32] preload with scale_kv
  deferred to between empty_epi wait and warpgroup_wait<1>
- kNumEpiStages=3 matching kNumKVStages to prevent inter-WG
  pipeline desynchronization
- epi_buf stride = BLOCK_Q*4+1 (17) for bank conflict reduction
- Bootstrap guard uses (num_total_kv_blocks | kv_block_idx) != 0
  instead of a persistent boolean to save 1 register

JIT launcher changes (SM90 path only):
- 12-parameter template with kNumEpiStages=3
- SMEM includes epi_buf (3 stages × BLOCK_KV × stride × sizeof(float))
- Thread count: num_math_threads + num_epi_threads + num_tma_threads

Performance (342 configs, H200 SXM):
  Speedup vs production: mean 1.065x, min 1.027x, max 1.111x
  Regressions: 0 out of 342
  Correctness: 295/295 full test configs pass
