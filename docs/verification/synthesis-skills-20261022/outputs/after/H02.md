# H02 — byte-preserving compaction diagnostic

**Disposition.** Retain the rejection of four-bit CACHE-Q quantization. Unchanged aggregate answer accuracy does not imply exact greedy-token equivalence; clipping calibration and an FP16 residual window supply neither exact reconstruction nor a universal equivalence argument [H02-E1, H02-E3–E4]. Frozen weights do not cure this correctness gap. There is no new evidence warranting reopening that same quantization proposal.

**One adapted experiment.** Consider only the independent byte-preserving page manager, with relocation restricted to a proven reader-quiescent boundary and coherent indirection/graph pointer updates [H02-E2–E3]. Hypothesis: consolidating fragmented live storage can release physical allocations beyond what existing paged KV allocation already achieves, without changing the logical KV values consumed by attention. This is a distinct allocator intervention, not a renamed quantization proposal.

**Selected components and compatibility.** Reuse packing plus indirection; omit four-bit encoding, learned clipping thresholds and residual-window handling. Required dependencies are byte preservation, unique ownership, logical token order and identity, no in-flight readers during moves, and invalidation/update of every reference that can retain a physical address. Concurrent reads and graph pointer reuse are explicit hazards in this runtime [H02-E2–E3]. A graph captured with a stale pointer cannot be made safe merely by updating a separate table. Determine whether replay consumes that table or requires recapture/patching; these interfaces are unknown. If safe quiescence cannot be established, the intervention is not executable as proposed.

**CPU-first design.** Use the saved allocator trace with the existing allocator replay to compare current allocation versus a proposed legal compaction schedule. Check whether unused space is actually reclaimable: moving whole pages without reducing live physical allocations is not a KV-memory improvement. Track peak allocated physical bytes/pages, reclaimable capacity and move counts/bytes where trace metadata supports them; missing page sizes or graph lifetimes remain unknown [H02-E3–E4]. Do not infer attention runtime, tensor values or a compaction share of the joint 35% claim [H02-E2].

Within a defined replay model, ownership checks and symbolic byte labels can verify that each legal move preserves every logical byte and updates references. Exercise stale graph references, concurrent-reader prohibition and reuse/alias cases. The trace has no actual KV tensor values and does not simulate attention numerics, so replay cannot establish model output equivalence or runtime synchronization correctness [H02-E3–E4]. A formal byte-preserving address transformation proves only its stated mapping invariants; actual kernels must obey them.

**Decision branches.** Advance only if replay exposes capacity recoverable beyond current paging and a defensible quiescence/reference-update design. Stop if no additional physical storage can be freed or the only viable mechanism changes KV values. Defer if trace information cannot establish safe relocation windows or graph-reference ownership. These are diagnostic outcomes, not serving results.

**Later requirements, not authorization.** Compare current paged allocation with compaction alone under matched long-context workloads, hardware, weights, precision, cache capacity policy and concurrency. Measure physical peak memory and serving overhead, including synchronization, movement and graph recapture. Preserve attention's logical inputs and numerical operation behavior; changing layout must not silently select a kernel or reduction order that changes greedy choices. Use the existing token-equality evaluator on matched prompts as a necessary regression check. Finite agreement cannot prove exact equivalence for all inputs; acceptance also needs an implementation-level correctness argument covering mapping, lifetime, concurrency and numerical semantics [H02-E4].

**Self-review.** Moderate confidence that the independent component can preserve bytes; local memory benefit and executable integration are unknown. Strongest objections are that current paging already captures the opportunity and graph/concurrency constraints erase practical value. The proposed CPU replay targets those objections without weakening correctness. No tests, code changes or GPU work were performed; evidence is supplied synthetic material only.
