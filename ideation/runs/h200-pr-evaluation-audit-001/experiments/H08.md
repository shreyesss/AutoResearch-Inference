# H08 — Avoid full-context candidate-indexer decode work on Hopper

Lane: **main**. Live-layout priority: **8**. Status: conditional plan; no GPU test or measured gain.

## Problem and causal hypothesis

Hopper can materialize scores over the entire compressed context before consuming only the selected candidate pool. Candidate-only FP8 paged scoring may cut memory traffic at very long context.

## Applicability to our H200 deployment

Verify actual text-indexer backend and absence of candidate-only path. Model uses2048 candidate blocks ×8 positions =16384 compact columns; measure actual compressed context and candidate coverage. Require contexts where dense work exceeds useful pool.

## Isolated control and treatment

A: dense Hopper decode indexer. B: #62463 direct paged-K candidate-only path, explicitly enabled. C: #62000 gather-based alternative as a separate arm. Keep candidate producer, prefill and top-k semantics fixed.

## Evaluation and predicted mechanism

E1: native agent-f75; E2: frozen Mooncake median/burst/cache-heavy. H200 capacity discovery and held-out confirmation in PROTOCOL.md.

Measure: Scored columns and bytes; candidate gather/intermediate allocation; indexer GPU time; selected top-k agreement/ties; context-stratified ITL and goodput.

## Why an additional evaluation is or is not needed

E1 fixed8K cannot establish long-context benefit. Inspect frozen Mooncake length histogram first. If insufficient, use existing synthetic/AIPerf client at32K/128K/512K/1M feasible lengths, exact output lengths, matched cache states and explicit OOM reporting; no new harness.

## Decision and falsification

Apply [the preregistered protocol](../PROTOCOL.md). Confirm path and missing behavior before spending GPU time. Support requires correctness, predicted mechanism movement and a useful held-out SLO outcome. Reject an active, well-measured change with no useful endpoint gain or a correctness/tail regression. Mark absent-path, underpowered or failed-replay cases inapplicable/inconclusive; do not label them disproven. Correctness lanes establish only scoped correctness.

## Evidence limits

Both PRs are alternatives. H20 long-context claims do not establish H200 benefit; #62000 reports a single-request regression. Short-context correctness for #62463 is incomplete. No expected gain asserted for E1.
