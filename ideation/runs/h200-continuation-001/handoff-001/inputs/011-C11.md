# C11 — Bound coordinated DP prefill release

Status: **Proposed; untested**. Updated: 2026-10-21 (Asia/Calcutta).

**Claim:** Compare existing scheduling with one of #51199/#61834, separately. Freeze a bounded policy after discovery; preserve dummy/pause/cancel participation.

**Why:** A prefill-heavy rank can stall decode peers during synchronized steps, producing decode tail spikes.

**Research finding:** Shared lead across all audits. A check performed only when a step starts does not guarantee a hard wall-clock waiting bound during long steps.

**Original design:** [consolidated family card](../runs/h200-cross-audit-comparison-001/families/C11.md). The original card is a pre-execution snapshot; current execution history is below.
