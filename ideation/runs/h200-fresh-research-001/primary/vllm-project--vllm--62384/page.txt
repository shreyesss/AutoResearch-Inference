Details
Reuse the existing replay batch, gather kernel and attention builders. The PCP-local batch retains its global scheduled view to derive tail boundaries and a common padding bound without CPU collectives. Select local slots before compaction, gather them in rank-major order, and align MoE routing IDs with the compact rows. Batches that would not shrink after padding keep full execution.
Unlike
#61554
's APC-disabled cold-prefill path, this builds on
#62183
for APC prefix hits and derives replay bounds from existing global PCP metadata. It retains the existing PCP restrictions and eager execution requirement, with no scheduler, generic model-runner or configuration changes. The branch is rebased on
#62183
now in main. AI assistance was used for implementation and static checks.
