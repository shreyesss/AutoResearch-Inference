# C15 — Shared Engram placement and exposed lookup cost

Status: **Proposed; untested**. Updated: 2026-10-21 (Asia/Calcutta).

**Claim:** Keep current shared ownership. First compare supported NUMA-local placement/settings; only then consider separately scoped shared-cuMem or lookup-threshold changes.

**Why:** CPU-offloaded lookup cost may depend on shared physical backing, NUMA placement and translation behavior even when private allocation waste is absent.

**Research finding:** Fresh proves dp_shared_memory=True on both replicas. Earlier H10 included multiple arms: its private exact-allocation arm is inactive, but shared placement is not disproven. dp_shared_memory does not identify physical backing by itself.

**Original design:** [consolidated family card](../runs/h200-cross-audit-comparison-001/families/C15.md). The original card is a pre-execution snapshot; current execution history is below.
