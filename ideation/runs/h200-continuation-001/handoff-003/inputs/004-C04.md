# C04 — Reduce CPU DP metadata synchronization overhead

Status: **Proposed; untested**. Updated: 2026-10-21 (Asia/Calcutta).

**Claim:** Use the reviewed low-latency CPU reduction implementation only for compatible groups and message ordering; preserve fallback and failure behavior.

**Why:** Tiny CPU reductions can delay dispatch even when GPU compute and GPU collectives are fast. Time waiting for late ranks can look like slow transport.

**Research finding:** All three identify #61767. Fresh finds patch conflicts and exposes group-local rank/tag/order checks. Two local DP4 groups differ from the source multi-node benchmarks.

**Original design:** [consolidated family card](../runs/h200-cross-audit-comparison-001/families/C04.md). The original card is a pre-execution snapshot; current execution history is below.
