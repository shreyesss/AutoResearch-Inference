DeepEP V2.5 introduces dedicated communication buffers for EP, PP, Engram, and bucket collectives, together with new primitives for redundant-expert load balancing. GPU kernels are now compiled through DeepJIT, while installation builds the host C++ extension.

This release also fully removes V1 and its NVSHMEM dependency.

New Features

  • Dedicated buffer APIs @LyricZhao
    • Split ElasticBuffer into EPBuffer, EngramBuffer, PPBuffer, and BucketBuffer, sharing the BufferBase lifecycle.
    • Add BufferAllocator for planning symmetric tensor allocations before buffer construction.
  • Expert load balancing @cqzhangyu @LyricZhao
    • Add EPBuffer.lb_prefetch_weights to transfer expert weights and quantization scales to redundant expert slots over NVLink.
    • Add EPBuffer.lb_reduce_grads to accumulate redundant experts’ FP32 gradients into the original experts.
    • These primitives support the dynamic expert-replication approach explored by MoonEP and UltraEP. Replication planning and token rerouting are supplied by the integrating framework.
  • Bucket collectives for CP and DP @jason-huang03 @bucket-xv @cqzhangyu @dromniscience @sphish
    • Batched all-gather, reduce-scatter, and all-reduce across NVLink, RDMA, and hybrid domains.
    • Sessions for communicating ordinary PyTorch tensors through temporary bucket storage.
  • EP improvements @LyricZhao
    • Deferred dispatch/combine epilogues for communication-computation overlap.
    • Cached expanded layouts and zero padding between experts.
  • Engram @tianr22 @sphish
    • Multi-layer storage on GPU or CPU, with one completion hook per layer.
  • Build and runtime @LyricZhao
    • Move GPU kernel compilation to DeepJIT.
    • Remove installation-time NVCC compilation and GPU architecture selection.

Notes

  • Migrate from ElasticBuffer to the dedicated buffer APIs.
  • V1 APIs, legacy documentation, and NVSHMEM support have been removed.
  • Bucket collectives, Engram, and PP remain experimental.
  • Requires NVIDIA Hopper or newer GPUs, CUDA 13.1+, NCCL 2.32.3+, PyTorch 2.10+ with CUDA support, Python 3.10+, and a C++20 compiler.
