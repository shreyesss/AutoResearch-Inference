# H03 — Callback activation applicability check

**Decision.** Retain FAST-C activation as a conditional CPU diagnostic, with low confidence in p99 TTFT value. Reject FAST-G for this current H200 deployment: its launch path requires SM100 instructions and has no SM90 fallback. An architecture port would be separate work with no demonstrated benefit here; its eight-SM100 throughput result does not support H200 DP4/EP4 p99 TTFT [H03-E3].

**Concrete hypothesis.** The pinned source already contains FAST-C, but callback batching is disabled. Enabling batching with its optional CPU dependency is a configuration/integration intervention, not a missing-code optimization [H03-E2, H03-E4]. Since the callback executes after completion, it cannot directly shorten that request's first-token latency. It could affect later requests only if callbacks contend for a CPU/event-loop/scheduler resource required for admission or first-token delivery. That causal pathway is currently unmeasured [H03-E1, H03-E2].

**What the numbers mean.** The author measured a callback microbenchmark from 100 microseconds to 40 microseconds at batch size 64: a 60-microsecond absolute reduction and 60% reduction in that component's duration under its benchmark conditions [H03-E1]. Do not infer equivalent invocation frequency, batch occupancy or exposed savings in this deployment. “60% faster inference” is unsupported. With one completion callback after 1024 output tokens, even an illustrative 60-microsecond saving per request would amortize to approximately 0.059 microseconds per output token; that conditional quotient is neither measured throughput gain nor TTFT savings [H03-E1, H03-E2]. No callback timing, CPU utilization, first-token timestamp or queueing exposure is supplied. Arrival/completion times alone cannot establish p99 TTFT or any nonzero expected improvement.

**Interpret prior failure accurately.** The earlier activation failed at startup due to a missing optional CPU package and served no traffic. It is an execution error and supplies no negative performance result [H03-E4]. Package availability in staging makes a dependency investigation newly useful, but does not show compatibility with the serving image, correct activation or resolved deployment readiness. Preserve the prior error separately from future inconclusive or invalidated hypothesis outcomes.

**Cheapest next investigation, proposed only.** Inspect the pinned callback dispatch and dependency declarations to identify the batching activation conditions, invocation granularity, flush/wait behavior and callback execution thread. Trace whether the same thread/resource handles request intake, scheduling or first-token emission. Compare the staging package version/ABI requirements with the serving image manifest using existing records; change neither environment. This is a zero-GPU source/configuration diagnostic. No additional source was actually inspected in this handoff because input access was restricted to the packet.

**Branches and eventual evaluator.** Stop prioritizing FAST-C for TTFT if source establishes that callback execution has no shared blocking resource or backpressure path to first-token work. Mark activation blocked if the package cannot be made compatible within scope. Shared-resource code paths support requesting targeted CPU scheduling/callback traces; they do not establish material contention. Return inconclusive if execution placement or measured exposure remains unknown, and stop retrieval once that measurement is the remaining discriminator.

If later authorized, compare batching off versus on with the required dependency, identical H200 DP4/EP4 workload/arrival pattern and 1024-token generation policy. A service evaluator must collect arrival-to-first-token timestamps for p99 TTFT, plus callback timing, CPU contention, batch sizes, completions and flush delays. No suitable existing first-token evaluator is identified in the records. Check correctness and completion semantics. Profile separately from scored runs. Self-review: strongest counterevidence is post-completion placement and missing contention evidence; advance only applicability diagnosis, defer service qualification.
