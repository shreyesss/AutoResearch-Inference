## Diagnostic strength

The probe executes a copied AST prefix plus exact compact/reallocate methods under manually supplied vector/cumsum/allocation/selector stand-ins. Its14 controls compare metadata values and a manual expansion consumer; the initial unwritten query array usefully catches an incomplete-write mistake. It does not execute the native budget selector, PyTorch allocations, CUDA cumsums, stream order or later kernels. The two unconditional-elision negatives support the gating need only. Reading the exact source chain supplies the broad overwrite argument; the finite cases alone are not exhaustive proof.

A missing effective manager/draft gate, omitted padding or deletion of CPU metadata would refute a naive implementation. The current proposal keeps those contracts. Later authorized native differential checks should cover budget0/partial/full, changed padded shapes, mixed requests and seeded outputs before standard workload timing. Actual AV-enabled fraction and exposed host/copy cost are still missing, so no service priority or additive ROI with HM65/CF59 is established.
