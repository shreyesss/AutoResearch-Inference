Purpose
When a target FULL CUDA graph pads its request count,
DPSyncState.num_reqs
describes graph capacity rather than the number of scheduled requests. Reusing that capacity for uniform drafter steps makes active DP ranks select larger draft graphs than needed.
This PR keeps the DP-wide maximum real request count alongside graph capacity and uses it for uniform drafter dispatch. It also shrinks online dummy-rank DFlash batches coherently across input preparation, graph dispatch, attention metadata, EPLB preparation, and draft generation. Startup graph capture retains its required capacity.
Test Plan & Result
The performance validation below uses the official nightly build at the PR base. This PR uses the same nightly plus only the four Python files changed by this PR; the runtime SHA-256 values were verified after the overlay was applied.

Model: DeepSeek-V4.1-Flash.
Hardware: two non-production nodes, one arm per node, with 8x NVIDIA H20 96GB per arm.
