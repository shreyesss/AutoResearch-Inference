# C25 native FULL-graph integration pilot: prospective contract

2026-10-20 UTC, after the positive component result and before native candidate execution. This is a separately named **controlled native draft-proposal and integration pilot**. It tests whether the qualified sampler activates inside the actual model's existing FULL graph, preserves native sampling and request lifecycle behavior, and retains measurable drafting-stage savings. It is not an ITL/service confirmation or a complete useful decode-cycle benchmark.

The C03 service endpoint, median ITL for requests with at least 50 output tokens at the frozen 0.5x trace, its 2% confirmation rule, tail/correctness guards, and two remaining full attempts are unchanged. A technically real gain below 2% can justify this new scoped result. No old unfavorable or inconclusive result is revised.

## Fixed collection and analysis

Warm each of the four native cells for eight untimed complete dummy cycles. Then collect **30 rounds**, each with all four cells and **eight timed cycles per cell**. Cell order rotates by round index modulo four and reverses on odd rounds, identically in A and B. No outcome-dependent stopping or added repeats. CUDA event allocation/collector is identical in both arms. Store every per-rank raw `forward_ms` and `drafter_ms`, descriptor, round, cycle and stream/device identity. All durations must be finite and positive; missing cells remain missing, with reasons.

Use installed same-stream `StepTimingCollector.collect()` and its end synchronization. Primary new endpoint is its **drafter-propose span**; the target-forward span is a separate control. The target sampler/rejection and the rest of the cycle are excluded. CPU launch gaps inside a CUDA event span can contribute idle time; do not describe the value as pure kernel time. No CPU/GPU clock joins or cross-device timestamp subtraction.

Report all four shapes and both outer replicas, with each DP rank visible. Per replica/shape/round, average the eight cycles on each rank and take the maximum rank mean as a declared coordinated-stage summary. Compare corresponding A/B round summaries; report absolute microseconds saved and percent change, plus all-rank distributions and target control. Bootstrap 30 paired round summaries with NumPy default_rng(20261020), 10,000 draws, percentile 95% interval. This estimates within-start precision only. A single A-then-B startup pair does not identify independent launch variation or remove order/thermal drift; no claim of confirmed general service improvement from that interval.

A valid positive native signal means source/activation/native correctness pass and a positive point gain with lower within-start interval above zero in at least one predeclared shape, with the entire matrix and any regressions disclosed. There is no universal 2% minimum and no requirement that every shape improve. A detectable mixed result is reported as mixed, not filtered away. Subsequent spending depends on effect size, relevance, target-control drift and integration evidence, not this classification alone. If the control or telemetry suggests launch drift comparable to the effect, label attribution unresolved rather than subtracting it to manufacture a win.
