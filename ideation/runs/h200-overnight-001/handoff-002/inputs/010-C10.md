# C10 — Preserve cache affinity at the final DP rank

Status: **Proposed; untested**. Updated: 2026-10-21 (Asia/Calcutta).

**Claim:** Use load-aware internal prefix tie-breaking (#52464), retaining salt isolation and load precedence. Shared frontend state is a distinct expansion beyond a local tie-break.

**Why:** Endpoint affinity can be lost when separate API workers choose different internal DP ranks, scattering warm prefixes.

**Research finding:** All three contain the idea; source high-load effects are weak/mixed. Actual router source differs between baseline snapshots and must be reconciled.

**Original design:** [consolidated family card](../runs/h200-cross-audit-comparison-001/families/C10.md). The original card is a pre-execution snapshot; current execution history is below.
