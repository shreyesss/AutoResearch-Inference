# C25 evaluator implementation notes

`tooling/c25_component.py` is an independent evaluator harness. Its expected outputs call the installed `UnquantizedEmbeddingMethod.apply` and installed `gumbel_sample`, using real BF16 checkpoint embedding/head tables. The candidate is imported only for the treatment. The installed unquantized method resolves dispatch itself; the harness records the selected function and rejects an unexpected batch-invariant environment. Persistent anchor indices and draft-column tensors match the installed loop. The reference's additional expected-embedding lookups are enabled only for correctness, never captured in timing graphs.

All shapes from the prospective addendum are covered: 1, 2, 4, 5, 7, 16, 32, 64. Buffers include extra state rows, a sixth unused cache/token column, seven unused vocabulary columns, and two unused token rows; full-array equality verifies their untouched sentinels. Invalid state mappings suppress cache writes while still exercising baseline padded-row sampling. State IDs and active output rows remain separate. Both Gumbel precisions are tested; timed arms use installed-default FP32 Gumbel.

Step 0–3 next embeddings are checked exactly. The last step has no next-embedding consumer and is not assigned a nonexistent requirement. A zero-active call exercises the candidate anchor wrapper's no-op and does not launch a zero-grid sampler. Every ordinary eager sample step checks counter reset; each repeated graph call also checks it. The 128 unchanged and 32 changed-input replay sequences run at every required shape in both precisions. A stale-counter mutant is rejected before any candidate kernel, then explicitly restored, as permitted by the contract.

Greedy fixtures independently specify winners for ties, block boundaries, the final vocabulary token and a BF16 rounding boundary. NaN cases are separately labeled comparator stress. Six negative controls must actually be rejected: step-dependent seed mutation, wrong cache state row, omitted BF16 rounding, stale arrival counter, corrupt token and corrupt cache. No finite mismatch tolerance is allowed.

The timing phase is unreachable until all earlier correctness fixtures succeed. Timing uses native contiguous `[64,5,129280]` cache and `[64,5]` token buffers; the extended sentinel strides are correctness-only. Both arms capture the entire five-step component with the same installed bias GEMM. Base logits are precomputed and excluded from both arms. Each size records all 30 paired blocks of 100 replays with alternating order and the frozen bootstrap. No native traffic weighting or service result is inferred. Full model EOS/cancellation/recovery, rejection integration and the optimistic ITL opportunity bound remain later gates.

Before root execution, the independent evaluator must approve the exact source hash in `c25-component-build.json`. Runtime exceptions retain partial `result.json` and stop; a failed allocation is not automatically rerun. No GPU, container, service or original environment was changed by writing this harness.
