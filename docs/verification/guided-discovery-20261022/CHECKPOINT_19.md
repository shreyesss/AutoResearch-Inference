### The accepted-diagnostic challenge mattered

For fixed physical expert rows n and fixed other tactic dimensions, target BLOCK_M is divisible by16 and the sum of its per-task aligned token extents equals16*ceil(n/16), independent of BLOCK_M. A smaller BLOCK_M cannot be credited with reducing that summed tensor-instruction token extent. Different task count, weight reuse, fixed TMA staging, occupancy and scheduling can still change elapsed time.

This corrects a simplistic M01/DA01 gain model; it does not prove that every tactic is equally fast or erase historical CPU diagnostic acceptance. Both routed linear phases and shared own-row paths were independently checked. The author's integer identity check is explicitly not kernel execution or a performance model.
