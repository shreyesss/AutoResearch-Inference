## Why this narrow component survives review

Pinned target `_rejection_kernel` (target-rejection.py562–710) distinguishes the non-greedy block branch from ordinary first-rejection sampling. With every admitted draft valid, `verifying` stays true throughout the block; each successful test replaces `accepted_length` with `i+1`. The final valid position has no next draft and sets `h=prefix_joint_ratio` (615–644). Therefore a passing final test forces accepted length to the admitted draft count regardless of earlier residual-derived thresholds. Earlier uniforms are indexed functions of seed/step/position, not mutations of RNG state (`spec_step_seed`, target-gumbel.py). Their omission introduces no sequential RNG-state dependency.

Current cumulative-ratio production precedes the full residual grid (1167–1226), which precedes rejection (1233–1277). A terminal flag established from that same stored FP32 ratio, original seed/step/position and original `<=` can gate residual vocabulary reads. Full-pass recovery is the bonus row and reads target logits directly (resample802–854). This argument concerns the existing native execution order and predicate, not the donor's more general real-arithmetic bound.

Round42's interior `h<=r` shortcut is a different, rejected numeric premise. FV86 uses native terminal `h=r` directly. C025 changes draft proposal generation; FV86 leaves the proposal distribution and generation work unchanged. Round39's logit-statistics fusion concerns the earlier statistics producer. They share cost regions but are not the same intervention and potential savings must not be added without joint controls.

- Fresh flags require one current-invocation owner, correct request-row versus state-slot mapping, initialization before greedy/empty early returns, and all consumer-readable extents. The existing residual producer reads expanded state indices; a producer indexed by request row cannot silently share that index space. Captured padding/lane and reused slots remain native gates, not proved by the dictionary fixture.

Keep failure fallback parallel; do not import the donor's serial unresolved-prefix scans or CDF normalizer assumption.

These are bounded adapter requirements, not evidence of an observed race or a reason to reject the useful component.

The ten author controls are source-inspired models supplied with thresholds/coins. The float32 rounding counterexample assumes explicit operation order and a scalar coin; it is not an observed native RNG/model trajectory. It supports caution about the broader interior bound, not a rejection of the terminal predicate. This review did not rerun or enlarge that fixture.

The2,068,480-byte maximum is conditional logical input bytes for four residual rows, full vocabulary129280 and two BF16 inputs. It is not measured traffic or time. Stats, cumulative ratios, launch, fallback work and recovery remain. The first decision-changing evidence is the **joint actual admitted length/full-valid completion frequency plus exposed residual-stage cost**, with original output/AV policy preserved. A high mean acceptance count alone is insufficient. Eligible complete passes may be common or rare; no frequency, latency or service forecast is retained.
