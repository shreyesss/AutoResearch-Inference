Add dsv41flash-fp4-h200-sglang-agentic-dspark: the H200 SGLang counterpart of the vLLM DSv4.1 Flash AgentX arm, built from the SGLang cookbook. DSv4.1 Flash has not shipped in an SGLang release, so the recipe uses the preview build lmsysorg/sglang:dev-dsv41 (digest recorded in the master config and changelog). TP8/EP8, native five-token DSpark (--speculative-algorithm DSPARK --speculative-dspark-block-size 5), thinking on with reasoning effort high, --mem-fraction-static 0.8, GPU-resident KV cache (kv-offloading: none), concurrency 1–128. Throughput uses the golden AL 3.51 (thinking on) through SGLANG_SIMULATE_ACC_LEN; accuracy evals keep real DSpark verification. --max-running-requests is 2 * CONC for AgentX subagent fan-out and the decode graph batch covers it, floored at the cookbook's 64 and capped at 128.

Hopper follows the cookbook's verified H200 cell and pins --attention-backend dsv4 --moe-runner-backend flashinfer_mxfp4. This PR also adds the shared SGLang section to the DSv4.1 Flash docs (EN/ZH) and the MODELS.md row; the sibling SKU PRs reference it.

Pre-downloaded checkpoint: the launcher resolves deepseek-ai/DeepSeek-V4.1-Flash through the cluster's persistent HF cache exactly as the vLLM arm does; the script only completes or resumes a partial download.

Validation: bash -n, YAML parse, exact-key matrix generation, and changelog append (no deletions) pass. GPU validation pending; full-sweep-fail-fast is set on this PR.

One PR per SKU: h100, h200, b200, b300, gb200, gb300 and mi355x are opened separately.
