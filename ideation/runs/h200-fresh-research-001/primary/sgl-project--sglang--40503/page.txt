Motivation
The SM90 FP4 decode/target-verify indexer uses a capacity-sized CUDA Graph grid while visible lengths change on device between replays. For a short live context, masking K loads still leaves FP4 dequantization and dot products running on entirely invisible tiles. For example, a row with 8,192 visible positions can reserve 1,048,896 output columns.
This change skips scoring for fully invisible tiles and writes
-inf
directly, reducing unnecessary work while preserving the dense logits interface.
Modifications
Add a tile-uniform branch using the current device-side visible length. Invisible tiles write
-inf
on every replay, including when previously visible tiles become invisible.
Preserve the original arithmetic, BF16 rounding points and masks for visible and partially visible tiles. The launch grid, output shape, cache layout and candidate-selection behavior remain unchanged.
Add focused decode correctness and CUDA Graph replay tests to the existing FP4 indexer test file.
The change adds no host-side length read, synchronization, extra kernel launch, dependency or configuration flag. The PR changes only the kernel and its test file.
Accuracy Tests
Validation hardware/software: NVIDIA H20-3e, PyTorch 2.11.0+cu129, Triton 3.6.0.
Existing FP4 indexer suite with the added tests:
23 passed, 36 skipped
. The skipped cases target Blackwell vectorized prefill.
11 added decode cases
cover empty/partial/full tiles; zero, negative and over-capacity lengths; heads 32/64; page sizes 64/128; strided inputs; padded page strides; and invalid inactive slot IDs.
An independent Torch FP64 reference checks FP4 decoding and the prescribed BF16 rounding points using controlled dyadic inputs. CUDA Graph replays grow/shrink visibility, change queries and slot mappings, and poison output buffers to detect unwritten tails.
Local compute-sanitizer memcheck:
11 cases, zero errors
, with the reference calculation moved to CPU in the validation harness.
Separate random-input A/B checks across ten shapes are bitwise identical to the baseline.
python -m pytest test/registered/kernels/ops/attention/test_fp4_indexer.py -q -rs
