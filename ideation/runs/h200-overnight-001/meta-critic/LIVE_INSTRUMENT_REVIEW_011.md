# Live instrument practical review before native B outcomes

Reviewed the frozen live observer, exact-source overlay generator, request
driver, reader, event-pool preflight and retained41CPUcontrols. Verified current
source/input hashes in the live, traffic and pool-preflight manifests. No GPU
or service action was performed by the meta-critic.

The instrument remains a useful bounded next diagnostic if independent native
and lifecycle review qualifies it. It wraps the actual non-dummy proposal path,
uses a fixed event buffer on the existing stream, records CPU metadata outside
the event span and resolves elapsed time only after strict drain. The existing
AsyncOutput synchronization precedes the CPU output callback; current verified
output is explicitly not assigned to the just-created proposal. Unjoined yield
is a disclosed limit, not a reason to invent a new mandatory generation model
for a stage-duration endpoint.

Eight deterministic all-rank primers reuse the repaired helper and establish
actual activity gauges and terminal counters before the unchanged AIPerf
workload. Exact primer IDs form a separate phase and cannot enter primary
profiling cells. The primary reader reports complete common/unmatched strata,
context distributions, coverage and chronological blocks. It uses descriptive
A-call-count weights, with no independent-event confidence interval or winning
cell gate. Summed overlapping GPU spans per committed client token remain a
resource-time ratio, not ITL or a complete decode-cycle cost.

No additional practical blocker was found in these reviewed paths. The exact
131,072-event per-rank pool is a concrete untested resource boundary, so its
separately reviewed one-device,120-second engineering preflight has good value
before another full model cold start. Retain its initialization memory/time
receipt; finite event timing alone does not prove the live model endpoint.
Future model allocation still needs independent B003 result/lifecycle review,
the live controller and remaining cumulative cost acceptance. This note does
not release that allocation or extend B003's deadline.

Before native results, allocation should consider the full matrix, component
mechanism scale, uncertainty and control/launch context. Neither one winning
cell nor unanimous positivity is an appropriate universal rule. Absolute target
forward drift cannot automatically veto a smaller draft saving because the
stages have different durations; broad unexplained drift still limits causal
attribution. Keep that judgment independent and preserve null or mixed results.

The two prior cold-load infrastructure failures identify a workflow improvement:
include observed startup cost and rehearse the specific new harness boundary
in the pinned environment before paying it. Root-owned process identity and
lazy metric publication had cheap CPU reproductions. This is a targeted
feasibility check, not a broad new checklist or permission layer. Retaining
qualified A002 evidence under a prospectively frozen continuation is the
intended evidence-aware behavior.
