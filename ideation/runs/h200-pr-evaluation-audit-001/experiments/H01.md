# H01 — Compare Humming with the observed Marlin MoE backend

Lane: **main**. Live-layout priority: **1**. Status: conditional plan; no GPU test or measured gain.

## Problem and causal hypothesis

MXFP4 expert GEMMs currently dispatch to Marlin on this H200 host. A different Hopper GEMM implementation may reduce expert time at the same routing, weights and precision.

## Applicability to our H200 deployment

Startup logs prove Marlin selection; Humming 0.1.16 is installed. Confirm that the pinned model route supports explicit Humming, expert shape 5120/2304 and current all-to-all prepare/finalize interface. Backend load and numerical fixtures precede any timed run.

## Isolated control and treatment

A: observed auto-selected Marlin. B: explicit --moe-backend humming, BF16 activations unchanged. Freeze TP1/DP4/EP4, DSpark k5 and every scheduler setting. Confirm actual kernel dispatch; do not silently include #59488 or FP8 activations.

## Evaluation and predicted mechanism

E1: native agent-f75; E2: frozen Mooncake median/burst/cache-heavy. H200 capacity discovery and held-out confirmation in PROTOCOL.md.

Measure: MoE GEMM and packing time per layer; EP collective time; tokens/expert distribution; HBM and available KV blocks; acceptance; qualified goodput and TTFT/ITL.

## Why an additional evaluation is or is not needed

E1 and E2 already exercise MoE. Add only upstream kernel/reference and fixed real-text quality fixtures because synthetic and Mooncake performance scoring cannot detect altered numerical semantics.

## Decision and falsification

Apply [the preregistered protocol](../PROTOCOL.md). Confirm path and missing behavior before spending GPU time. Support requires correctness, predicted mechanism movement and a useful held-out SLO outcome. Reject an active, well-measured change with no useful endpoint gain or a correctness/tail regression. Mark absent-path, underpowered or failed-replay cases inapplicable/inconclusive; do not label them disproven. Correctness lanes establish only scoped correctness.

## Evidence limits

PR is closed without merge; it motivates a backend A/B, not a blind cherry-pick. Author tests use an older DeepSeek V4 checkpoint/H20; headline gains are not a forecast for this host.
