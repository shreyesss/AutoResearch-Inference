Summary
select the Marlin MoE M tile through a shared helper
let batched Marlin estimate per-expert load from the current token assignments instead of the padded capacity
retain the capacity-based fallback for direct callers
DeepEP low-latency uses a capacity-padded batched expert layout. Selecting
block_size_m
from that capacity can choose a 64-row tile even when the current request has very few valid assignments per expert, adding substantial padding work.
topk_ids.numel()
is shape metadata and does not introduce a device-to-host synchronization.
