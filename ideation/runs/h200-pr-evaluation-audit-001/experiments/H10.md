# H10 — Improve CPU-offloaded Engram placement and allocation

Lane: **main**. Live-layout priority: **10**. Status: conditional plan; no GPU test or measured gain.

## Problem and causal hypothesis

CPU-offloaded Engram tables may waste pinned host capacity or suffer remote-NUMA reads and translation overhead. H200 host topology differs from GB200 coherent CPU/GPU systems.

## Applicability to our H200 deployment

Engram offload and embedding_across_dp are on. Verify shared physical backing, per-group NUMA ownership, page size, actual host-memory path and existing allocation code. Do not duplicate shared tables blindly.

## Isolated control and treatment

A: existing allocation and affinity. B: NUMA-local allocation/worker placement only. Separate C: exact registered allocation #59849. Separate D: measured H200 thresholds for sorting/inline lookups based on #59327, never copied GB200 thresholds.

## Evaluation and predicted mechanism

E1: native agent-f75; E2: frozen Mooncake median/burst/cache-heavy. H200 capacity discovery and held-out confirmation in PROTOCOL.md.

Measure: Host RSS/PSS, locked bytes, NUMA locality, lookup latency by row count, PCIe traffic, CPU/GPU overlap and EP rank waits; prefill TTFT and goodput.

## Why an additional evaluation is or is not needed

E1/E2 already use Engram. Add read-only NUMA/host-memory counters and short Nsight diagnostic capture. Correct allocation lifetime/sharing tests precede runs.

## Decision and falsification

Apply [the preregistered protocol](../PROTOCOL.md). Confirm path and missing behavior before spending GPU time. Support requires correctness, predicted mechanism movement and a useful held-out SLO outcome. Reject an active, well-measured change with no useful endpoint gain or a correctness/tail regression. Mark absent-path, underpowered or failed-replay cases inapplicable/inconclusive; do not label them disproven. Correctness lanes establish only scoped correctness.

## Evidence limits

#59327 enables measured thresholds only on Blackwell; H200 adaptation is a new measured tuning task. #59849 evidence is GB10, not proof of H200 speedup.
