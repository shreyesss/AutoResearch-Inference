# H09 — Enable Hopper length-aware candidate-block top-k

Lane: **main**. Live-layout priority: **9**. Status: conditional plan; no GPU test or measured gain.

## Problem and causal hypothesis

Candidate-block selection may scan max-context-width scores even when live contexts are short. Valid block counts plus a Hopper-compatible selector can avoid the padded tail.

## Applicability to our H200 deployment

Installed _has_deep_select is SM100-only; candidate_blocks still lacks valid_blocks. #59204 is draft; validate actual FP32 SM90 extension, not just the library BF16 benchmark. Check workspace/capture safety.

## Isolated control and treatment

A: current full-width selector. B: correctness-qualified SM90 DeepSelect build/integration. C: B plus #61039 valid-block selection; isolate extension replacement from length-awareness.

## Evaluation and predicted mechanism

E1: native agent-f75; E2: frozen Mooncake median/burst/cache-heavy. H200 capacity discovery and held-out confirmation in PROTOCOL.md.

Measure: Allocated versus valid block count; top-k time and memory traffic; FP32 top-k agreement/ties, out-of-range/NaN handling; E1/E2 goodput.

## Why an additional evaluation is or is not needed

Reuse E1/E2 plus upstream exact selector tests and graph-replay tests. Include short-context/large-max-context cases; fixed8K request is appropriate for padded-work diagnosis.

## Decision and falsification

Apply [the preregistered protocol](../PROTOCOL.md). Confirm path and missing behavior before spending GPU time. Support requires correctness, predicted mechanism movement and a useful held-out SLO outcome. Reject an active, well-measured change with no useful endpoint gain or a correctness/tail regression. Mark absent-path, underpowered or failed-replay cases inapplicable/inconclusive; do not label them disproven. Correctness lanes establish only scoped correctness.

## Evidence limits

Not a drop-in #61039-only H200 gain: its useful selector requires SM90 integration. PR59204 body is a template; patch source, not author speedup, supports the mechanism.
