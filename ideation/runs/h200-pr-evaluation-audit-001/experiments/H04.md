# H04 — Recover prefix reuse without corrupting draft context

Lane: **main**. Live-layout priority: **4**. Status: conditional plan; no GPU test or measured gain.

## Problem and causal hypothesis

Prefix restoration and draft-group junction rules can either veto usable target hits or expose draft KV that was never written, lowering acceptance and increasing repeated prefill.

## Applicability to our H200 deployment

Record target/draft group IDs, cache-hit boundaries, actual final DP rank and acceptance on warm hits. Verify annotation ownership and existing equivalent fixes before selecting a patch.

## Isolated control and treatment

Diagnose first. Compare A versus exactly one matching fix: restored-context masking (#47926), reachable sibling junction positions (#62278), or appropriate DSpark group handling (#57110). Never stack all three as the first arm.

## Evaluation and predicted mechanism

E1: native agent-f75; E2: frozen Mooncake median/burst/cache-heavy. H200 capacity discovery and held-out confirmation in PROTOCOL.md.

Measure: Token-weighted hits per KV group; computed prefill tokens; acceptance by draft position and hit length; TTFT; output/reference correctness.

## Why an additional evaluation is or is not needed

Existing E1 prefixes and Mooncake cache-heavy measure benefit. If existing samples miss exact sibling/unaligned-block boundaries, add small two-turn/sibling fixtures using the same client; this is the documented correctness coverage gap.

## Decision and falsification

Apply [the preregistered protocol](../PROTOCOL.md). Confirm path and missing behavior before spending GPU time. Support requires correctness, predicted mechanism movement and a useful held-out SLO outcome. Reject an active, well-measured change with no useful endpoint gain or a correctness/tail regression. Mark absent-path, underpowered or failed-replay cases inapplicable/inconclusive; do not label them disproven. Correctness lanes establish only scoped correctness.

## Evidence limits

A hit-rate increase alone is not success. Mooncake trace replay does not imply a MooncakeStore connector is installed.
