## Model statement and experiment

Explicitly activate Humming for the shipped MXFP4 experts, then compare fixed indexed and grouped GEMM paths at unchanged activation precision. The supplied startup log selects MARLIN, and the installed automatic priority list omits Humming, so an indexed override alone cannot change execution. Installed code already exposes the override; #59488 supplies a narrower indexed-selection predicate for V4.1 on SM90 with compatible communication. First verify that explicit Humming selection reaches this loader and that the actual communication backend qualifies. The transfer hypothesis is that indexed execution reduces the complete routed-expert cost enough to improve serving. No supplied measurement establishes that cost or a Humming advantage over this MARLIN deployment.

**Control:** Supplied pinned MARLIN deployment, preserving both replicas, API2, seq64, MBT16384, graphcap512, cache settings, Engram, DSpark k5, and telemetry. Primary workloads remain native agent-f75 8K/1K prefixes and fixed-schedule Mooncake adapted to H200 seq64. Establish the actual activation schema before matching backend arms.

**Correctness:** Validate routing and expert outputs at exact shipped geometry, swiglu_limit10 and intermediate rounding; empty/uneven EP ranks; target and drafter execution; graph replay; KV rollback and real rejection. Use independent numerical references and a quality subset. Apply the common TF32 prerequisite if affected prenorm paths execute.

**Cost:** Low integration cost if existing controls work; loader integration cost otherwise unknown. Future serving cost is P8*T_hours/N_valid_output_tokens using the full eight-GPU node; P8 and required run duration are unknown.

**Held out condition:** Separate cache-isolated 1K/1K diagnostic; unseen ragged arrivals, expert skew, long contexts, mixed prefill/decode, and cold/warm prefix conditions. Keep seq128 outside this comparison.

**Inconclusive if:** Backend/schema activation is unverified, rank coverage is missing, intervals remain broad, or output/acceptance and graph differences confound attribution. Insufficient eligible opportunities cannot support a zero-effect conclusion.

**Metrics:** Across every rank and replica, count actual backend/GEMM calls over eligible MXFP4 expert-call opportunities, separated by target/draft and execution phase. Record routed-row distributions and full MoE spans. Measure request TPOT=(last-first token time)/(server output tokens-1) for outputs>1, TTFT tails, exact throughput, qualified goodput, replay lag, KV blocks/preemption, draft/verify/accepted deltas, and quality.

**Rejects if:** Adequately covered, precise comparisons rule out the prespecified useful improvement, or the best eligible Humming arm regresses. Reject indexed preference if grouped wins. Unrepaired numerical, routing, or distributed failures veto the affected path.

**Supports if:** A fixed Humming arm improves the prespecified serving metric over MARLIN without guardrail failures. Indexed preference additionally requires improvement over grouped at identical precision. Confirm small gains with at least five alternating paired full-run blocks, drift checks, and run-level intervals; mechanism diagnostics must agree with the attribution.

**Treatment:** Future sequence: source/configuration eligibility check; activation verification; correctness; unprofiled three-arm screen; separate mechanism profiling; paired confirmation and held-out evaluation. Force each Humming GEMM choice statically. If explicit Humming cannot reach the installed MXFP4 loader, defer execution until a bounded integration is established.
